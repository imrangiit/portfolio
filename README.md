# Imran — Dyeson Portfolio

An interactive 3D portfolio for Imran, known online as Dyeson. It introduces Imran as a beginner developer learning Python, C, C++, and HTML, and sharing his interest in making tools, Telegram bots, and Discord bots.

The experience is built with React, Three.js, React Three Fiber, GSAP, and Vite. It includes an illustrated corridor with About, Gallery, Studio, and Contact scenes.

## Run locally

Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
